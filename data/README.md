# data/

Сюди боти кладуть JSON для показу на сайті (наприклад, `jobs.json` зі свіжими вакансіями,
`cars.json` з вигідними авто). Сторінки сайту читають ці файли через `fetch('data/...')`.

Правила:
- Лише публічні дані: без телефонів, імен, @username людей, токенів і ключів.
- Один файл на тему, перезаписувати цілком (не дописувати).
- Після запису запускати `..\publish.ps1` не частіше разу на годину.
