# Сайт Signal Only

Статичний сайт для GitHub Pages: чистий HTML + CSS, без збірки, без cookies і лічильників, без платних сервісів.
Створено 31.10.2026. **Ще не опубліковано.**

## Що тут лежить
| Файл | Що це |
|---|---|
| `index.html` | головна: що таке Signal Only, боти, «скоро» (Signal Jobs, Signal News) |
| `alert.html` | Signal Alert (бот тривог) + дисклеймер, що він не замінює офіційні сигнали і застосунок «Повітряна тривога» |
| `auto.html` | Signal Auto (бот оголошень авто) + таблиця Безкоштовно / Преміум / VIP |
| `privacy.html` | політика конфіденційності |
| `blog/` | список статей і 3 статті |
| `assets/style.css` | усі стилі (світла й темна тема — автоматично) |
| `favicon.svg` | іконка |
| `sitemap.xml`, `robots.txt` | для пошукових систем |
| `.nojekyll` | каже GitHub Pages віддавати файли як є |

## Що треба заповнити перед публікацією
1. **Домен-заглушка `https://signalonly.com`** стоїть у `sitemap.xml` і `robots.txt`. Чи вільний цей домен і чи він
   ваш — НЕ перевірено. Замініть на справжню адресу (наприклад, `https://<ваш-логін>.github.io/signal-only-site`
   або свій домен). Посилання між сторінками відносні, їх міняти не треба.
2. **`privacy.html`**: заповнено 01.11.2026 (Signal Only, maxiglad@ukr.net).
3. **Боти.** Узяті з коду: Signal Alert = `@AirAlerts_TheBot` (канал `@airalerts_thebot_chanel`),
   Signal Auto = `@filtrautobot`. Якщо ботів перейменуєте — замініть у `index.html`, `alert.html`, `auto.html`,
   `privacy.html` і статтях (пошук за `t.me/`).
4. **Ціни Преміуму/VIP** на сайті не вказані числами (лише «в Telegram Stars», деталі в боті), бо вони можуть
   змінюватись. Таблиця можливостей у `auto.html` відповідає `car-bot\config.py` на 31.10.2026.
5. **Картинка для соцмереж (og:image)** не додана: Telegram і Facebook не показують SVG. Якщо захочете гарне
   прев'ю посилання — зробіть PNG 1200×630, покладіть як `assets/og.png` і додайте в `<head>` кожної сторінки
   `<meta property="og:image" content="https://ВАШ-ДОМЕН/assets/og.png">`.

## Як переглянути локально
Просто двічі клацніть `index.html` — відкриється в браузері. Інтернет не потрібен.

## Як опублікувати на GitHub Pages (безкоштовно) — по кроках
Нічого з цього ще не зроблено. Публікувати лише коли самі вирішите.

1. Зареєструйтесь або увійдіть на https://github.com.
2. Натисніть **«+» → New repository**. Назва, наприклад, `signal-only-site`. Оберіть **Public**
   (безкоштовний GitHub Pages працює з публічними репозиторіями). Натисніть **Create repository**.
3. На сторінці нового репозиторію натисніть **«uploading an existing file»**.
4. Перетягніть у вікно **весь вміст** папки `signal-only-site` (файли й папки `assets`, `blog`; разом із
   `.nojekyll` — якщо Провідник його не показує, увімкніть «Вигляд → Приховані елементи»).
   Перевірте, що в списку немає нічого зайвого чи секретного. Натисніть **Commit changes**.
5. Відкрийте **Settings → Pages**. У «Build and deployment» → **Source: Deploy from a branch**,
   **Branch: main**, папка **/ (root)** → **Save**.
6. За 1–3 хвилини зверху з'явиться адреса сайту: `https://<ваш-логін>.github.io/signal-only-site/`.
7. Замініть `https://signalonly.com` у `sitemap.xml` і `robots.txt` на цю адресу (або свій домен) і завантажте
   ці два файли ще раз (Add file → Upload files).
8. (За бажанням) Свій домен: купіть домен у реєстратора, у **Settings → Pages → Custom domain** впишіть його,
   а в реєстратора додайте DNS-записи, які покаже GitHub. Увімкніть **Enforce HTTPS**. Домен — платний крок,
   лише після вашого «так».
9. (За бажанням) Додайте сайт у Google Search Console (безкоштовно) і надішліть `sitemap.xml`,
   щоб статті швидше з'явились у пошуку.

## Правила
- Без cookies, лічильників і зовнішніх скриптів (так у політиці конфіденційності). Якщо колись додасте
  аналітику — оновіть `privacy.html`.
- Дисклеймер на `alert.html` і в статті про тривоги не прибирати.
